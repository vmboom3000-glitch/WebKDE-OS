WebKDE OS
Веб‑настольная среда, вдохновлённая KDE Plasma, полностью работающая в браузере.

Проект представляет собой полноценную мини‑операционную систему, написанную в одном HTML‑файле: рабочий стол, окна, файловая система, магазин приложений, настройки, уведомления, Alt+Tab, трей и многое другое.

✨ Возможности
🖥 Рабочий стол
·	Иконки приложений
·	Двойной клик для запуска
·	Генерируемые обои
·	Темы оформления (Dark / Breeze)
🪟 Оконный менеджер
·	Перетаскивание окон
·	Изменение размера
·	Сворачивание / разворачивание / закрытие
·	Анимации открытия и закрытия
·	Поддержка Alt+Tab с мини‑превью
📂 Файловая система
·	Диски C: и D:
·	Папки и файлы
·	Создание TXT файлов
·	Переименование
·	Удаление в корзину
·	Восстановление из корзины
·	Drag‑and‑drop TXT файлов в Блокнот
·	Сохранение в localStorage
🧰 Встроенные приложения
·	Файловый менеджер
·	Блокнот (с автосохранением и открытием файлов)
·	Калькулятор
·	Браузер (встроенный iframe)
·	Терминал (команды: help, apps, open, notify, theme, date…)
·	Магазин приложений (установка веб‑приложений)
·	Настройки (тема, обои, звук, системная информация)
🛒 Магазин приложений
Установка веб‑приложений:
·	VS Code (vscode.dev)
·	MDN Docs
·	TerminalTemple
·	KDE.org
🔔 Уведомления
·	Всплывающие уведомления
·	Центр уведомлений
·	История уведомлений
·	Очистка истории
🕒 Панель задач
·	Кнопка «Пуск»
·	Закреплённые приложения
·	Список открытых окон
·	Системный трей:
o	Часы + дата
o	Раскладка (RU/EN)
o	Громкость
o	Сеть (online/offline)
o	Батарея (симуляция)
o	Кнопка центра уведомлений
🔊 Звуковая система
·	Системные звуки (уведомление, ошибка, открытие окна)
·	Регулировка громкости
🔐 Экран входа
·	Анимация
·	Любой пароль
·	Кнопка выключения (возврат на экран входа)

🏗 Архитектура проекта
Основные модули
·	Window Manager — управление окнами, z-index, анимации, Alt+Tab
·	App Manager — запуск встроенных и веб‑приложений
·	File System — виртуальная FS в localStorage
·	Notification System — всплывающие уведомления + центр уведомлений
·	Desktop Environment — рабочий стол, панель задач, трей
·	Settings Engine — темы, звук, обои
·	Store Engine — установка веб‑приложений
Хранение данных
Используется localStorage:
·	webkde-fs — файловая система
·	webkde-installed-apps — установленные приложения
·	webkde-notifs — история уведомлений
·	webkde-theme — текущая тема
